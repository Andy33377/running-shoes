# Изображения для сайта

Используются две папки в **`public/images/`**:

## 1. Шоссейные кроссовки — `public/images/shoes/`

- **Карточки категорий (Men / Women):**

  - `men.jpg` — карточка «Men»
  - `women.jpg` — карточка «Women»

- **Товары (шоссейные):** файлы `1.jpg`, `2.jpg`, … `12.jpg` — по порядку соответствуют первым 12 товарам в каталоге.

## 2. Трейловые кроссовки — `public/images/trail-shoes/`

- **Товары (трейловые):** файлы `1.jpg`, `2.jpg`, `3.jpg`, `4.jpg` — для четырёх трейловых моделей в конце списка.

Если папка у тебя называется **«trail shoes»** (с пробелом), переименуй её в **`trail-shoes`** или в коде в `src/data/mockData.ts` замени `IMG_TRAIL` на `"/images/trail%20shoes"`.

Имена файлов можно поменять: открой `src/data/mockData.ts` и подставь свои имена вместо `1.jpg`, `2.jpg` и т.д.
